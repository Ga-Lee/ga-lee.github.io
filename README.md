# Jia Li's academic homepage

Personal academic website, published at https://ga-lee.github.io/.

This is a buildless static website. Edit `index.html` for content, `refinements.css` for layout overrides, and `assets/` for images.

GitHub Pages publishing source: `main` branch, `/ (root)` directory.

To preview locally, run `python3 -m http.server 8765` from this directory.
